# Smart Task Manager

A lightweight command-line task manager written in C++. Add, list, complete and delete tasks, with automatic saving to `tasks.txt`.

## Build

```
g++ -std=c++17 -Wall -Wextra -pedantic src/main.cpp -o task-manager
```

## Run

Windows:

```
.\task-manager.exe
```

Linux or macOS:

```
./task-manager
```
